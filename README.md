# Tokyo Xtreme Racer Save Builder

Browser-only save editor for **Tokyo Xtreme Racer** (2025, UE5, Genki)
`UserData_00.sav` files. Built with Vite + React 19 + TypeScript. No backend —
your save never leaves the browser.

## Features

- **Upload-and-edit** mode: load your real `UserData_00.sav`, edit everything, re-export a CRC-correct file.
- **Build-from-template** mode: start from a fresh 1-car ZC33S save if you don't have one.
- **Player stats**: CP, BP (PP), day, mileage totals.
- **Garage**: add, remove, duplicate cars (new IDs from `MyCarIdSrc`, no key reuse).
- **Chassis swap**: 82 dealer + 3 demokit + 77 buyable customs (incl. 6 DLC collabs).
- **Engine swap**: 6 swaps (2JZ-GTE, 20B, RB26DETT, VR38DETT, JNC, 1LR-GUE).
- **Per-car tuning**: 12 kinds × up to 6 levels with bought-max / tuner-effect cheat warnings.
- **Perk tree**: force-acquire all perks toggle (also unlocks the full dealer / tuner inventory).
- **Strict validation** against legit caps (500M CP, 2500 BP) with parser-max guard.
- **CRC-correct export**: CMTA re-wrap + CRC32-IEEE footer (slicing-by-8) on every download.

## Save format (verified)

- Layout: `[CMTA 4B][GVAS payload][00 00 00 00 + u32LE CRC]` (8B footer).
- Footer = **CRC32-IEEE of `file[4:-4]`**, stored little-endian.
- Engine: UE 5.6, save version 3, 84 custom-version GUIDs.
- `MyCars` is `Map<int, struct>`; new keys use `++MyCarIdSrc`.
- `SelectedMyCarId` must reference an existing key.
- Fixed-size engine structs: Vector/Rotator 24B (3×f64), Quat 32B, LinearColor 16B, DateTime 8B, Guid 16B.

See `src/lib/gvas.ts` and `src/lib/txr.ts` for the codec.

## Repo layout

- `src/lib/` — codec, no deps, no UI: `crc32.ts`, `txr.ts`, `gvas.ts`, `types.ts`.
- `src/data/` — game tables: `cars.ts` (82+3+77), `engines.ts` (6), `tunes.ts` (12), `dressup.ts`, `caps.ts`, `validation.ts`, `perkTree.ts`, `gameTables.ts`.
- `src/components/` — React UI: `ModeSelect`, `PlayerForm`, `GarageList`, `CarEditor` (+`CarPicker`), `PerkPanel`, `ValidatePanel`, `save-utils`.
- `public/template.sav` — completion-state template (1 stock ZC33S), generated by `mktemplate.ts`.
- Root scripts (NOT bundled with the app, run with `npx tsx`):
  - `rtcheck.ts` — codec round-trip vs `OptionData_stripped.sav` (6KB) + `UserData_stripped.sav` (1.5MB).
  - `e2e.ts` — full UI flow (load template → edit → export → re-parse).
  - `mktemplate.ts`, `check-dlc.ts`, `verify-template.ts`.
